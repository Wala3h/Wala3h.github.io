# Portfolio of outputs

## 1. [Interactive OLAP Dashboard Application using Steam Games data set](https://github.com/Wala3h/STADVDB_MCO1)
A data analytics web application built using the Streamlit and Python. This application allows users to filter, view, and visualize general metrics of the Steam Games data set as well as the different game metrics such as the game statistics, reviews, and player activity. The application was built to be run locally using Python, Streamlit, and MySQL as the database. 

Role: Sole application designer and developer, while contributing to data pre-processing for analytics

## 2. [Forum Website](https://github.com/CarandangR/CCAPDEV-MCO) 
A project made using a common tech stack, MERN (MongoDB, Express, React, Node.js), while also utilizing Handlebars for templating the different pages of the website. The forum contains features such as role-based access (user, administrator), communities, and post interactions (reply, upvote, downvote).

Role: Front-end designer and developer, implementation of post interactions

## 3. [Emulation of a Multitasking Operating System](https://github.com/saxzeee/CSOPESY-Machine-Project)
A C++ project aiming to emulate the processes of how an Operating System works. The emulation involves command processing, scheduler implementation, memory management, and demand paging. 

Role: Command processing implementation, Quality Assurance (QA), display design

## 4. [Ride booking Website Mockup](https://github.com/jeanneeugenie/STSWENG-XX23)
A website mockup that was aimed to help in finding transportation around DLSU Laguna Campus. The website contains role-based features (rider, driver, administrator), where drivers can coordinate with riders for easier transportation outside and around the campus. The project was built on React + Material UI, Node, Express, and Node.js.  

Role: Front-end designer and developer
